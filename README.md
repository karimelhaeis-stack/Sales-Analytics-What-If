# Sales Analytics & What-If Scenario

An interactive Power BI sales dashboard featuring an **integrated What-If scenario**.

## Overview
The dashboard combines sales performance metrics with scenario analysis. By adjusting assumptions, users can explore potential effects on the displayed KPIs and compare alternative outcomes.

## Key areas
- Interactive sales KPI analysis
- Integrated What-If scenario
- Comparison of potential outcomes

## Technology
Microsoft Power BI
